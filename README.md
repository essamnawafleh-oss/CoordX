# كورد اكس · CoordX

برنامج ويندوز **مجاني لوجه الله تعالى**. بياخذ جداول الإحداثيات من **الصور** أو **ملفات PDF** أو **الإكسل**، وبيحوّلها لنقاط على الأوتوكاد بملف **DXF**.

**تطوير:** عصام النوافلة - Essam Nawafleh

> 🤲 إذا سهّل عليك البرنامج شغلك، لا تنسَ المطوّر من دعوة بظهر الغيب بالتوفيق والسداد.

## التنزيل

من صفحة [Releases](../../releases) نزّل واحد من الملفين:
- **`CoordX-Setup-x.y.z.exe`**: برنامج تثبيت، بيعمل اختصار على سطح المكتب.
- **`CoordX-Portable-x.y.z.zip`**: نسخة محمولة بدون تثبيت. فك الضغط وشغّل `CoordX.exe`.

البرنامج بيشتغل **بدون إنترنت**.

## طريقة الاستخدام

1. **افتح الملفات:** اكبس «فتح ملفات»، أو اسحب الملفات للبرنامج. بتقدر تفتح صورة وحدة، أو عدة صور مرة وحدة، أو PDF فيه أكثر من صفحة أو أكثر من جدول.
2. **راجع:** كل قطعة بتطلع بالقائمة، وصورتها جنب جدول الأرقام. لما تختار نقطة بالجدول، بتتلوّن مكانها على الصورة.
   - 🟥 **أحمر:** غلط أكيد، مثل رقم ناقص أو عدد خانات مختلف أو نقطة بعيدة.
   - 🟨 **أصفر:** قراءة غير أكيدة، راجعها.
   - ✓ **أخضر:** طول الضلع مطابق لرقم مكتوب على المخطط.
3. **عارض الرسمة (DXF):** من تبويب «عارض الرسمة» بتشوف الرسمة نفسها اللي رح تطلع بملف الـ DXF. أي تعديل بالجدول بيبين فيها فوراً.
   - **كبسة على نقطة:** بتحددها بالجدول.
   - **دبل كلك:** بتفتح نافذة تعدّل فيها رقمها وإحداثياتها.
   - **كلك يمين:** تعديل، أو إضافة نقطة بعدها، أو حذف.
   - **«تحريك النقاط بالسحب»:** بتسحب النقطة لمكانها الصح.
   - **تراجع (Ctrl+Z):** بيرجع أي تعديل.
4. **صدّر** بصيغة DXF أو Excel أو CSV (Civil 3D)، أو **تقرير PDF** للطباعة: صفحة لكل قطعة فيها الرسمة بمقياس رسم (مثل 1:500) ومسطرة مقياس، وجدول الإحداثيات، والأطوال، والمساحة بالمتر المربع والدونم.
5. **افتح بالأوتوكاد:** بكبسة وحدة بيحفظ القطعة DXF وبيفتحها. إذا الأوتوكاد مفتوح بيفتح الملف فيه، وإذا مسكّر بيشغّله.

### أدوات الصورة

- **قراءة منطقة:** ارسم مستطيل حول جدول الإحداثيات بس، والبرنامج بيقرأ داخله. مفيدة للصور الزحمة أو اللي فيها أكثر من جدول.
- **تدوير 90°** يمين أو يسار، أو **زاوية دقيقة** بالدرجات.
- **تعديل الميلان:** بيكشف ميلان الصور المصورة بالموبايل وبيعدّله تلقائياً. بعدها اكبس «إعادة القراءة».

### قراءة ملفات DXF

افتح رسمة أوتوكاد (DXF) وبيطلع منها جدول الإحداثيات:
- كل **Polyline مغلق** بيصير قطعة.
- إذا ما في Polylines، بياخذ **النقاط (POINT)** أو **البلوكات**.
- أرقام النقاط بياخذها من النص القريب من كل نقطة.

بعدها بتصدّرها على Excel. ملفات **DWG** لازم تنحفظ DXF من الأوتوكاد أول (Save As ← DXF).

### ملف الـ DXF فيه

| الطبقة | المحتوى |
|---|---|
| `POINTS` | النقاط (POINT) |
| `POINT_NO` | أرقام النقاط |
| `BOUNDARY` | حدود القطعة (Polyline مغلق) |
| `LENGTHS` | أطوال الأضلاع |
| `TABLE` | جدول الإحداثيات |
| `AREA` | اسم القطعة والمساحة |

إذا صدّرت أكثر من قطعة بملف واحد، كل قطعة بتاخذ طبقات خاصة فيها، مثلاً `30_POINTS`.

### الصور الصعبة (خط يد، صور مش واضحة)

اعمل منها ملف إكسل بأي أداة، وافتحه بالبرنامج. أفضل ترتيب للأعمدة:

**رقم النقطة | X | Y | Z**

البرنامج بيتعرف على أسماء الأعمدة (X/E/شرقي، Y/N/شمالي، Z/منسوب). وإذا انعكسوا، في زر **«تبديل X ↔ Y»**.

## For developers

```bash
pip install -r requirements.txt
python main.py
python -m pytest tests
```

- OCR: [RapidOCR](https://github.com/RapidAI/RapidOCR) (ONNX, offline, models bundled).
- Digital PDFs are read from their text layer; scanned pages are OCR'd.
- Windows builds are produced by GitHub Actions (`.github/workflows/build.yml`). Push a tag `vX.Y.Z` to publish a release with the installer and portable zip.
